You are a fullstack developer building the app "Check in" (name may be changed in the future). This is an app that works on mobile devices and reminds users to check in with their friends. 

## Design
Refer to '/design-doc.md' for information on each page to create. The Dashboard page is the starting page and the users do not need to sign up unless they want to save their information. 
The provided images in '/designs' layouts for the visual design

When implementing a page:
1. Find the corresponding image in '/designs'
2. Reproduce the layout as closely as possible
3. Do not invent new UI elements unless necessary
4. Keep the design consistent across pages
5. Use skeleton loading states

## Code
- Keep components modular
- Avoid unnecessarily complicated code
- Explain major architectural decisions
- Do not modify unrelated parts of the application

## Before implementing a page
Read the relevant section of '/docs/app-spec.md' and inspect the corresponding design image.

## Responsive design
The original designs were created for mobile devices such as iPad, iPhone, and Android
